# stuck_on_the_bridge

[直接玩《還在橋上》](https://wilsondenq879.github.io/stuck_on_the_bridge/?route=guanxin-tsmc)

遊戲版本 v0.8.2。支援電腦、手機觸控，以及瀏覽器辨識的標準藍牙手把。

## GitHub Pages

發布來源使用 GitHub Actions。推送到 main 後，工作流程會檢查遊戲、上傳 dist，接著部署到 Pages。可在 Actions → Deploy game to GitHub Pages 查看進度或手動重跑。

## 遊戲說明

可玩的 Three.js 汽車／白牌機車通勤原型，涵蓋竹北、竹東二重埔到台積電12A及聯發科總部。道路中心線與遠山使用實際圖資；建築外觀與交通規則採遊戲化重建。所有瀏覽器依賴已附在專案內，不需要外部 CDN、不蒐集定位。

## 啟動與操作

在本資料夾執行 `npm start`，瀏覽器開啟 `http://127.0.0.1:4173/`。亦可執行 `python3 -m http.server 4173 --directory dist --bind 127.0.0.1`。必須透過 HTTP／HTTPS，不能直接雙擊 HTML。手機使用發布後的 HTTPS 網址；電腦的 localhost 不能直接在手機開啟。

| 操作 | 鍵盤 | 標準手把 |
| --- | --- | --- |
| 油門 | W / ↑ | RT / R2，類比深度 |
| 約六成油門 | Shift + W | 輕壓 RT / R2 |
| 煞車 | S / ↓ / 空白鍵 | LT / L2 |
| **直接橫向移動** | **A / D、← / →** | 左搖桿／方向鍵 |
| 看左右 | Q / E、拖曳畫面 | 右搖桿 |
| 車內／車尾跟拍 | V | Y / △ |
| 輔助跟車 | C | X / □ |
| 按喇叭 | H | RB / R1 |
| 暫停 | P / Esc | Menu / B / ○ |
| 出發／繼續 | 畫面按鈕 | A / × |

A 向左、D 向右橫移，放開立刻停止橫移，不累積轉向角、不會自行畫圓。鏡頭只跟隨道路原有彎曲。遊戲採固定通勤路線與循線輔助，尚不能任意轉進支路。C 是可隨時介入的遊戲跟車輔助，兩種車都可用。

手機使用雙拇指配置：左側類比搖桿控制左右橫移，放手回中；右側為大面積油門與煞車踏板。油門按住後上滑加大、下滑減小，顯示25–100%力道，陡坡可穩定使用約六成油門。喇叭、跟車與車內／車尾視角按鈕位於踏板上方。每個控制獨立追蹤手指，可同時轉向與踩踏板；鬆手／觸控取消、暫停、切換分頁及旋轉螢幕時清除輸入。橫向與直向皆可玩。行車時上方只留一行路名、距離、號誌與必要事件短提示；右上地圖或事件提示可開啟暫停的路況面板，查看地圖、事故統計、停等、里程與扣分。暫停可選1×、2×、3×；車流、事件和號誌一起加速。

藍牙手把先在作業系統配對，再回遊戲按任一鍵。透過 Gamepad API 讀取瀏覽器辨識為 `standard` 的配置；斷線會暫停，非標準配置提示改用觸控／鍵盤。此次完成映射、類比觸發器與輸入合併測試，**未使用實體藍牙手把或實體手機測試**；手機畫面使用瀏覽器尺寸與指標操作驗證；多指所有權及取消流程另有程式測試。[Gamepad API](https://developer.mozilla.org/en-US/docs/Web/API/Gamepad_API/Using_the_Gamepad_API)

竹北：自強南路 → 經國大橋 → 慈雲路 → 園區一路 → 公司外公共道路。南下左側依序是 **Costco、迪卡儂**，兩店以實際建物輪廓定位。汽車經園區一路高架跨越光復路；白牌機車走平面，園區內另循實際機車道，之後重新匯流。共用路口的汽機車號誌同步。

二重埔：中興路四段 → 關東橋 → 光復路一段 → 園區一路平面 → 公司外公共道路，不會錯誤繞去經國大橋。二重埔起點使用公共路口，未指定住家或特定建案。

目的地依公司官網核對：

- **台積電12廠採12A／總部**：力行六路8號，與12B不同。[台積電廠區資料](https://www.tsmc.com/chinese/aboutTSMC/TSMC_Fabs)
- **聯發科總部**：篤行一路1號。[聯發科聯絡資料](https://www.mediatek.com/zh-tw/company/contact-us)

抵達點設在 OSM 所繪製廠區車道與公共道路的接入點，停在廠區外；並非實測警衛門位置，不模擬廠區內道路。

**台68立體交會**依圖資分層重建：經國大橋上方是往竹北匝道，主線從橋下通過，並非把整條快速道路都架在玩家頭頂。匝道橋面、護欄、橫向車道及避開玩家路線的橋墩均有模型；高度為原型參數，非工程測量。

## 每天擲骰，不選事件

選出發地、公司、車種後，按「擲骰，發動今天」。六顆骰子決定事故與生活事件，獨立種子決定天氣及地震。一般出發每次重新擲骰；桌面點左下角骰子，手機點右上地圖 →「今日骰子與事件」，可看當天記錄與重播連結。快速體驗只選路段，仍然隨機擲骰，並會略過地方序章。

- 國道事故使容量下降、匝道排隊累積、改道需求進入市區；車輛跟車、併道、停等形成回堵。事故清除後隊伍逐步消化。
- 紅燈、測速照相、闖紅燈照相及黃網線未淨空。實際通過／占用才判定，照相有閃光與記錄。所有單次紅燈不超過60秒；橋頭挑戰紅燈55秒。路口連續幾輪排不到，總等待仍可能超過1分鐘。
- 路邊違停、綠色 Uber Eats／粉色 foodpanda 外送車占道、機車突然切入，均為可影響車距的實際交通車，不只顯示通知。外送角色與行為皆屬虛構。
- 經國大橋短綠長紅挑戰，模擬一波車放不完；秒數不是現地時制。
- 綠燈亮後、前方確實有空間而玩家停超過4秒，後車會按喇叭、閃大燈；紅燈或前方塞住不觸發。車內後照鏡可看後車。
- 竹北完整通勤可能抽到「喜來登周邊天坑」獨立序章；路面是否塌陷再擲機率，可向左避讓。掉落會拖吊復位並加90秒，不會卡死。這是使用地區稱呼的虛構街廓，並非飯店事故還原。
- 二重埔完整通勤可能抽到「陡坡地下室」獨立序章。大油門會空轉、燒胎與冒煙，約六成油門較易爬坡；持續全油門一段時間後也可恢復抓地。未指涉特定建案。

二重埔序章已延長至190m，從地下室爬坡後，經過六棟14層集合住宅、綠地與社區大門，再駛入2–4層透天街廓。社區立面參考使用者提供的星都匯B區照片，地下室坡度及動線仍為遊戲化重建。

兩個序章完成後切換到相應真實路線起點，**不是額外連續地理路線**。照相點、速限與扣分是遊戲參數，不是實際執法資料或罰鍰。

## 風景、天氣與聲音

- 二重埔取消竹北式隨機高樓補景。中興路採2–4層透天與零散店面、光復路採3–5層老店屋；田地與廠辦有退縮空間。較高量體集中在集合住宅，二重埔區段上限14層。光復路後排保留圖資明確標記的少數高樓。
- 透天增加褪色磁磚、鐵窗、外掛冷氣、鐵捲門、雨棚、水塔與招牌；電線桿及架空線沿路排列。低層街屋前景為依街景參考重建，並非每棟都逐戶測量。
- 建物仍會剔除侵入可行駛路面者；外牆窗格按實際樓高比例重畫，不再把3–4層的量體畫成十幾層。
- 遠山採128×128真實區域DEM、高程範圍約−5至2156m，沒有任意把山擺在正前方。十八尖山位在竹北起點西南，飛鳳山／中坑山在東南，五指山在南南東，標籤依各山實際座標放置。
- 每日遊戲天氣機率：晴天56%、雨天30%、颱風14%。雨與颱風有降雨粒子、能見度、路面、抓地、風偏與雨刷變化。地震18%機率，短時間震動及車潮減速；尊重系統減少動態效果設定。上述機率與時點完全是遊戲設定，不是預報。
- 動態引擎、路噪、雨聲、輪胎空轉、煞車、玩家與外部喇叭。原創84 BPM合成BGM，無外部歌曲。
- 六種路況各有四句台灣中文配音與字幕。跟上一輛前方有空間、仍持續慢行的車五秒後，會聽到「開這麼慢，車子壞了是不是？」等吐槽。整排車陣停等逾25秒會講塞車台詞。鬼切、外送違停、擦撞也各有台詞。綠燈後前方可走，玩家停著超過四秒，後車會閃燈、按喇叭並用另一個聲音催促。
- 同種路況的四句輪過才重抽，整體配音間隔至少12秒。暫停選單的「怒罵」可單獨關閉台詞與字幕，總聲音與BGM可分別調整。

## v0.7.1 機車道、園區高架與台68

園區一路的路燈、樹幹、樹冠及人行道依汽機車實際分流的路幅留出淨空。機車貼近路緣時會限制左右移動，油門與煞車仍各自控制前進速度。從竹北或二重埔看園區高架，橋面、橋底與側面共用同一條線形，橋下光復路維持平面通行。

台68竹科交流道依 OpenStreetMap 重建八個進出方向的主線、匝道及銜接道路，北向經國大橋採實際中心線。分岔與匯入的護欄留出開口。水平接點可用原始圖資節點檢查，垂直坡度、路幅及橋下淨高為模型設定。[台68竹科交流道匝道圖資](https://www.openstreetmap.org/way/99596878)

## 資料來源與可用範圍

圖資於2026-11-06 UTC取得。© [OpenStreetMap contributors](https://www.openstreetmap.org/copyright)，衍生路網／建物／山峰資料保留 ODbL 1.0。四條路線保留原始 way IDs、座標、標籤及來源。

園區高架為雙向三車道，原型採晨間南下兩線配置；實際可變車道以現地號誌為準。白牌機車分流參照[市議會紀錄，印刷頁389](https://www.hsinchu-cc.gov.tw/upload/79/2024062610394318077%E7%AC%AC11%E5%B1%86%E7%AC%AC5%E6%AC%A1%E8%87%A8%E6%99%82%E6%9C%83%E8%AD%B0%E4%BA%8B%E9%8C%84.pdf)及[竹科2024年公告](https://www.sipa.gov.tw/home.jsp?contlink=ap%2Finformation_1_view.jsp&dataserno=202401230005&menudata=ChineseMenu&mserno=201001210001&serno=201001210001)；尚未完整重現污水處理場內晨間分流。慈雲路平面車道參照[市府2026年10月16日完工稿](https://www.cna.com.tw/postwrite/chi/447232)。[國道匝道回堵機制參考](https://gdd.hsinchu.gov.tw/News_Content.aspx?n=1406&s=247757)。

遠山資料來自 [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/) 的9張Terrarium高程磚，採[Terrarium格式](https://github.com/tilezen/joerd/blob/master/docs/formats.md)解碼，內容約2017年、取樣間距約260–290m，來源與SHA256記於 `dist/data/terrain.json`。[高程歸屬說明](https://github.com/tilezen/joerd/blob/master/docs/attribution.md)。道路附近做平坦銜接，遠處保留DEM；不應用來判讀實際道路坡度。

這是有實際路線的風格化交通原型，**尚非逐棟寫實場景、完整新竹數位孿生或即時路況**。道路寬度缺漏、橋高坡度、建物立面與部分高度、對向道路、車流量及號誌時制採原型近似，尚未以現地流量校準。畫面與交通模型仍可持續細化。

## 驗證與程式結構

執行 `npm test` 可跑自動測試，涵蓋四條路線與兩種車輛的事故日抵達、道路與號誌、隨機事件、駕駛操作、建物與地形，以及配音。語音測試檢查每句的音檔、字幕配對、重複與冷卻、播放中斷，並實際推進車流檢驗慢車、整排塞車和碰撞的觸發條件。

瀏覽器完成：兩種視角、汽機車切換、四條路線選擇、手動橫移、觸控油門、喇叭、音效開關、颱風雨刷、序章與公司抵達畫面。詳細驗收表另附。

- `dist/app.js`：遊戲流程、HUD、鍵盤／觸控、手把與重播。
- `dist/sim.js`：跟車、號誌、事故需求、取締與後車催促。
- `dist/day.js`：每日骰子、天坑與陡坡序章。
- `dist/controls.js`：標準手把與輸入合併。
- `dist/touch-controls.js`、`mobile.css`：手機搖桿、類比踏板、多指追蹤及橫直向安全區排版。
- `dist/neighborhood.js`、`neighborhood-world.js`：二重埔分區、透天立面、田地／廠辦、六棟集合住宅及社區出口。
- `dist/world.js`：路面、車、建物、商場、橋樑、駕駛艙、雙視角與後照鏡。
- `dist/environment.js`、`environment-world.js`：天候、地震、山景、建物避路。
- `dist/audio.js` 負責引擎、喇叭、BGM與對白播放，`dist/driver-lines.js` 定義字幕與抽句規則，配音檔位於 `dist/audio/`。
- `dist/geo.js`：實際道路、高度與路段取樣。
- `dist/data/routes/`：四條正式路線及公司資料；舊 `route.json` 僅留作回歸測試。
- `dist/data/terrain.json`、`overpasses.json`：實際DEM與台68分層幾何。
- `dist/vendor/`：Three.js 0.180.0，附MIT授權。

## v0.8.1 關新路街景對照修正

依使用者提供的2026年3月關新路街景重做此區。去程起點向北移約224公尺，沿合法南行方向開向東京中城主塔；回程延長約233公尺至對向車道。

關新路改用119棟地圖建物輪廓，其中85棟有OSM樓層。主塔採23層、鄰塔13層的量體，增加朝街陽臺、垂直構件與開框屋頂；店面與住宅依各自輪廓配置。中央分隔島加入低矮植栽，路邊增加斜列機車停車格，行道樹採較細的枝幹與疏透樹冠。建物高度以每層3.2公尺估算，缺樓層者採示意高度，停車格位置及植栽配置亦為視覺重建。

照片取景方向推估為從北行車道回望西南，遊戲出發依道路合法行進方向呈現。來源保存在 dist/data/guanxin.json。[東京中城建商資料](https://beautybuild.com.tw/hotcase/MeiLiYiSen/) · [23層主塔圖資](https://www.openstreetmap.org/way/827291354)


## v0.8.2 諧音地名

遊戲選單、導航、迷你地圖、山峰標示、建築與商店招牌統一使用同音異字。例「關薪路、糠橋、名糊路、驚幗大橋、抬雞店、連發瞌、薪築、築北、貳蟲圃」。遊戲顯示名稱由 dist/name-aliases.js 管理，game-text.js 套用至文字與畫布，資料來源、座標與選項識別值仍供原有程式讀取。讀取資料時不改寫地圖原始名稱。
